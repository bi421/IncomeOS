## Trust boundaries

- Evidence confidence is not capability level.
- Capability level is not job fit.
- Job fit is not application outcome.
- Local execution does not prove external submission.
- External outcomes require evidence.
- Outcomes do not automatically upgrade skills.
- Profile updates require human verification.

## Hardened components

- Evidence provenance
- Application verified-evidence context
- External outcome CLI
- Human verification CLI
- End-to-end dry run
- Regression tests

## Remaining real-world limitation

Automatic browser/email/job-portal ingestion is not enabled.
